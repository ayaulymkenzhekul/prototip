# Raw Sources

`raw/` хранит исходные материалы для LLM Wiki.

Правило: raw-источники считаются первичными материалами и не переписываются без необходимости. Wiki хранит сжатое, структурированное знание, полученное из этих источников.

## Что сюда класть

- экспорт важных чатов;
- заметки со встреч;
- исходные PDF/TXT/MD документы требований;
- Swagger/OpenAPI, если нужно сохранить снимок;
- скриншоты или ссылки на артефакты, если они важны для решений.

## Структура

- `raw/chats/` — исторические чаты и их обработанные summaries.

Если источник большой или содержит приватные данные, сначала согласовать с владельцем проекта, что его можно хранить в репозитории.
