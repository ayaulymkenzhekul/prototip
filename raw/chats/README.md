# Raw Chats

Сюда складываются важные исторические чаты, которые нужно использовать для пополнения LLM Wiki.

## Когда сохранять чат

Сохранять raw-файл, если чат относится к типу A:

- длинное обсуждение;
- важные продуктовые решения;
- архитектурные решения;
- спорные договоренности;
- решения по ролям, статусам, UI, API, справочникам или процессу.

Если чат относится к типу B:

- короткое обсуждение;
- быстрая правка;
- мелкое исправление;

то raw-файл можно не создавать, достаточно обновить соответствующие страницы `wiki/`.

## Формат файла

Имя файла:

```text
YYYY-MM-DD-тема.md
```

Шаблон:

```md
# [Тема обсуждения]

Source: Codex/Claude/ChatGPT chat, [месяц год]
Topic: [одна строка о чем чат]

## Что узнали о проекте

- Факты о структуре, стеке, поведении системы.

## Ключевые моменты

- ...

## Принятые решения

- Выбрали X, потому что...
- Отказались от Y, потому что...

## Нерешенные вопросы

- ...
```

## Важное правило

Перед обновлением wiki нужно сверить информацию из чата с текущим кодом и актуальными документами.

Если в чате написано X, а в коде или новых документах сейчас Y, нужно зафиксировать конфликт и спросить пользователя, что актуально.
