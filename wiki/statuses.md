# Statuses

## Статусы ДВ и сметы

| Статус | Значение | Следующий статус |
| --- | --- | --- |
| Черновик | ДВ создается и еще не отправлена. | На согласовании |
| На согласовании | ДВ отправлена в ЕСЭД. | Согласовано / На доработке |
| Согласовано | Документ согласован в ЕСЭД и готов к СМАКС. | Утверждена / На осмечивании / На доработке |
| Утверждена | Документ прошел финальное подтверждение перед распределением. | На осмечивании |
| Внешнее согласование | Дополнительный внешний этап. | На утверждении / На доработке |
| На утверждении | Ожидает финального решения. | Утверждена / На доработке |
| На доработке | Вернулся заявителю с замечаниями. | Черновик / На согласовании |
| Отложено | Координатор СМАКС временно не назначил ДВ сметчику. | На осмечивании / Возврат заявителю |
| На осмечивании | Назначен сметчику. | Смета готова / На доработке |
| На уточнении | Сметчик задал вопрос, нужен ответ заявителя. | На осмечивании |
| Смета готова | Сметчик обработал позиции. | На проверке / Закрыто / Выгружено |
| На проверке | Смета передана старшему сметчику. | Закрыто / На осмечивании |
| Выгружено | Итоговый документ передан в целевую систему или подготовлен к передаче. | Закрыто |
| Закрыто | Процесс завершен. | - |

## Важные правила статусов

- `Черновик -> На доработке` напрямую не использовать.
- `На доработке` возникает после возврата из ЕСЭД, СМАКС или от сметчика.
- `Согласовано` и `Утверждена` не должны означать одно и то же.
- Если процесс после ЕСЭД сразу идет в СМАКС, `Утверждена` можно использовать как внутренний подтвержденный статус СМАКС.

## Внутренние статусы проверки

| Статус | Значение |
| --- | --- |
| Готов | Данные подтверждены. |
| Нужно уточнение | Нужен ответ или проверка. |
| Нет решения | Не выбран вариант обработки. |
| Ошибка | Блокирующая проблема. |
| Дубль | Найдена похожая запись. |
| AI-подбор | Позиция предложена ЦА. |
| Из справочника | Позиция выбрана из справочника. |
| Ручной ввод | Добавлено пользователем вручную. |

## Статусы позиции сметы

| Статус | Значение |
| --- | --- |
| Не обработана | Позиция еще не проверена сметчиком. |
| В работе | Сметчик подбирает сметную работу или расценку. |
| Готово | Позиция обработана и может входить в итог. |
| Требует уточнения | По позиции нужен ответ заявителя или проверка данных. |
| Отклонена рекомендация | Сметчик отклонил рекомендацию ЦА; причина должна быть зафиксирована. |
