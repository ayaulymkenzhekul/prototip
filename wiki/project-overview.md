# Project Overview

## Название

Рабочее название продукта: **Смета РК / Цифровой ассистент**.

В пользовательском интерфейсе не стоит без необходимости выносить "Смета РК" как крупный бренд в sidebar, потому что продукт шире, чем только сметы: он покрывает ДВ, согласование, СМАКС, осмечивание и справочники.

## Тип системы

Веб-система для создания, проверки, согласования, распределения и осмечивания дефектных ведомостей.

## Основная задача

Автоматизировать путь дефектной ведомости:

```text
Заявитель -> ЕСЭД -> СМАКС -> Сметчик -> Старший сметчик -> Закрыто
```

## Проблема

Без системы процесс распадается на ручные действия:

- заявитель описывает дефект свободным текстом;
- работы и материалы выбираются вручную;
- в справочниках появляются дубли;
- согласующие получают неполные документы;
- СМАКС вручную распределяет заявки;
- сметчик тратит время на уточнения;
- участники не видят единую картину статусов.

## Решение

Система должна дать единое рабочее пространство, где:

- заявитель создает ДВ через ЦА или вручную;
- Цифровой ассистент помогает заполнить документ;
- live-предпросмотр показывает документ до отправки;
- блок готовности подсвечивает ошибки и предупреждения;
- ЕСЭД согласует или возвращает;
- СМАКС назначает сметчика;
- сметчик подбирает расценки;
- старший сметчик проверяет итог;
- справочники поддерживаются без дублей и грязных данных.

## Главный продуктовый принцип

Это не просто "сметная система". Это маршрутная система для дефектной ведомости с AI-помощью, справочниками и осмечиванием.
