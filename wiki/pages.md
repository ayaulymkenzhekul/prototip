# Pages

## Основные страницы

| Страница | Назначение |
| --- | --- |
| Рабочий стол заявителя | Общая навигация и задачи заявителя. |
| Создание ДВ через ЦА | Создание документа из обычного текстового описания. |
| Ручное создание ДВ | Пошаговый мастер: описание, данные, работы, предпросмотр, примечания, согласование. |
| Предпросмотр ДВ | Live document workspace с блоком готовности и чатом ЦА. |
| Очередь ЕСЭД | Согласование или возврат ДВ. |
| Очередь СМАКС | Распределение согласованных ДВ на сметчика. |
| Рабочее место сметчика | Входящие сметы, прогресс и действия. |
| Черновик сметы | Подбор и проверка расценок. |
| Справочники | Объекты, материалы, работы, единицы измерения. |

## Предпросмотр ДВ

Должен быть live workspace, а не PDF viewer.

Состав:

- слева: ведомости, дефекты, объекты, справочники;
- центр: документ, stepper, tabs, готовность, секции ДВ;
- справа: ЦА, next best action, input.

## Блок готовности

Текущая договоренность:

- карточка "Готовность к осмечиванию" должна быть свернута по умолчанию;
- пользователь может раскрыть список проверок кнопкой "Развернуть";
- кнопка должна менять текст на "Свернуть";
- это нужно, чтобы первый экран не занимался большой карточкой и документ был виден выше.

## Sidebar

Текущая договоренность:

- крупный текст "Смета РК" в глобальном sidebar убран;
- причина: название сужает продукт до сметы, хотя система покрывает весь маршрут ДВ;
- верхний блок sidebar должен быть компактным.
