# Decisions

Эта страница фиксирует важные решения из чатов и правок, чтобы они не потерялись.

## UI и терминология

| Решение | Статус | Причина |
| --- | --- | --- |
| Помощника называть "Цифровой ассистент" | Принято | Помощник работает не только со сметами. |
| Не использовать "МЕСАЛИНА" | Принято | Это старое/неподходящее название для текущего продукта. |
| Убрать крупный текст "Смета РК" из sidebar | Принято | Sidebar не должен сужать продукт до сметы. |
| Поле "Год сметирования" заменить на "Год реализации" | Принято | Год относится к реализации работ. |
| Номер ДВ делать в формате `ДВ-YYYY-MM-XXX` | Принято | `AOK-ES...` выглядел как номер сметы/заявки. |
| Карточку готовности свернуть по умолчанию | Принято | Документ должен быть выше на экране. |

## Документ и предпросмотр

| Решение | Статус | Причина |
| --- | --- | --- |
| Предпросмотр ДВ должен быть live workspace | Принято | Пользователь должен видеть и исправлять документ, а не только PDF. |
| После шага "Работы" должен идти "Предпросмотр" | Принято | Нельзя сразу отправлять на примечания/согласование без проверки документа. |
| В ЕСЭД и СМАКС "Открыть полную ДВ" должно быть read-only | Принято | Эти роли просматривают и принимают решения, но не редактируют ДВ. |

## СМАКС и сметчик

| Решение | Статус | Причина |
| --- | --- | --- |
| Выбор сметчика в СМАКС должен быть компактным | Принято | Не нужно постоянно показывать все 3 карточки; выбор раскрывается по клику. |
| Действия у Есенова должны быть в порядке 1-2-3 | Принято | Утверждающему нужен понятный порядок действий. |
| Цифры рядом со статусами в СМАКС убрать | Принято | Они визуально мешали и не были нужны в этом месте. |

## Справочники

| Решение | Статус | Причина |
| --- | --- | --- |
| Справочник работ должен иметь красивый режим колонок | Принято | Пользователь должен видеть разделы и карточку узла без кривого вложенного дерева. |
| В режиме колонок не показывать лишние уровни, если выбран верхний раздел | Принято | Уменьшает визуальный шум. |
