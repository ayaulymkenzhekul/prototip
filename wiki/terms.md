# Terms

| Термин | Значение |
| --- | --- |
| ДВ | Дефектная ведомость. Основной документ процесса. |
| ЦА | Цифровой ассистент. AI-помощник, который анализирует данные, предлагает действия и помогает пользователю. |
| ЕСЭД | Этап согласования ДВ утверждающим лицом. |
| СМАКС | Этап регистрации, проверки и распределения ДВ на сметчика. |
| Осмечивание | Подбор расценок и формирование сметы по позициям ДВ. |
| Сметчик | Специалист, который обрабатывает ДВ и готовит смету. |
| Старший сметчик | Пользователь, который проверяет готовые сметы. |
| Справочник | Каталог объектов, материалов, работ или единиц измерения. |
| Blocking error | Блокирующая ошибка, из-за которой нельзя отправить документ дальше. |
| Readiness | Готовность ДВ к следующему этапу. |
| Live document workspace | Предпросмотр документа, который остается интерактивным, а не статичным PDF. |

## Важные договоренности по терминам

- Помощника называть **Цифровой ассистент**, не "Цифровой сметчик".
- Не использовать старое название "МЕСАЛИНА".
- Поле "Год сметирования" переименовано в **Год реализации**.
- Номер ДВ должен отличаться от номера сметы или заявки. Использовать формат вида `ДВ-2026-06-001`.
