# LLM Wiki проекта

Эта папка — база знаний проекта "Смета РК / Цифровой ассистент".

Цель wiki — сохранять продуктовые, технические и UX-решения так, чтобы они не терялись между разработчиками, сессиями ИИ и будущими этапами разработки.

Wiki построена по принципу LLM-maintained knowledge base:

- исходники и большие документы остаются отдельно в `raw/`;
- в `wiki/` хранится сжатое, структурированное знание;
- каждая страница отвечает за отдельную тему;
- `index.md` помогает быстро найти нужную страницу;
- `log.md` фиксирует, что было добавлено или изменено;
- `schema.md` задает правила для будущих обновлений.

## Как пользоваться

1. Новому разработчику сначала читать [index.md](index.md).
2. При работе над фичей читать тематическую страницу: роли, статусы, UI, сценарии, интеграция.
3. После важных решений обновлять соответствующую страницу и добавлять запись в [log.md](log.md).
4. Если появляется новый источник знаний, кратко занести его в [sources.md](sources.md).
5. Если появляется важный исторический чат, обработать его по [chat-ingest.md](chat-ingest.md) и при необходимости сохранить summary в `raw/chats/`.

## Главный принцип

Не держать важные решения только в чате. Если решение влияет на продукт, интерфейс, роли, статусы, API или процесс разработки, оно должно попасть в wiki.
