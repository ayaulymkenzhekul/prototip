# Metrics

Метрики результата из актуальной версии требований.

## Процессные метрики

- среднее время создания ДВ;
- среднее время согласования ДВ;
- количество возвратов на доработку;
- причины возвратов;
- среднее время назначения сметчика;
- среднее время подготовки сметы;
- количество вопросов сметчика заявителю;
- количество закрытых смет за период;
- нагрузка по сметчикам;
- количество просроченных задач.

## Метрики качества данных

- доля ДВ без блокирующих ошибок;
- доля ДВ, отправленных без возврата;
- количество дублей материалов;
- количество дублей работ;
- количество ручных вводов вместо выбора из справочника;
- количество записей справочников на проверке;
- количество архивированных устаревших записей;
- доля позиций с видимым источником данных.

## Метрики ассистента

- сколько рекомендаций ЦА принято;
- сколько рекомендаций ЦА изменено;
- сколько рекомендаций ЦА отклонено;
- причины отклонения рекомендаций;
- средняя уверенность рекомендаций;
- количество случаев, когда ЦА запросил уточнение;
- количество ошибок, исправленных через ЦА.
