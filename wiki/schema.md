# Schema: правила ведения LLM Wiki

## Назначение

Этот файл объясняет будущему ИИ-агенту или разработчику, как поддерживать `wiki/`.

## Слои знаний

| Слой | Назначение | Правило |
| --- | --- | --- |
| Raw sources | Полные документы, код, скриншоты, переписки, Swagger, заметки. | Хранить в `raw/`, не переписывать без необходимости. Использовать как источник. |
| Wiki | Краткие структурированные markdown-страницы. | Обновлять при каждом важном решении. |
| Index | Навигация по wiki. | Держать актуальным. |
| Log | Хронология изменений знаний. | Добавлять запись после каждого пополнения wiki. |

## Стиль страниц

- Писать на русском языке.
- Писать понятно для разработчика, дизайнера, аналитика и заказчика.
- Не описывать весь код построчно.
- Фиксировать продуктовую логику, договоренности, ограничения и решения.
- Использовать таблицы для ролей, статусов, маршрутов и сценариев.
- Не использовать устаревшее название "МЕСАЛИНА".
- Помощника называть "Цифровой ассистент".
- Не называть систему только "Смета РК" в UI, если это сужает смысл до смет.

## Что обновлять

Обновлять wiki, если изменились:

- название продукта или терминология;
- роли;
- статусы;
- маршрут ДВ;
- поведение ЦА;
- UI-правила;
- структура страниц;
- интеграция с backend/API;
- правила справочников;
- важные решения по прототипу.

## Как добавлять новый источник

1. Добавить запись в `sources.md`.
2. Извлечь ключевые знания.
3. Обновить тематические страницы.
4. Добавить запись в `log.md`.
5. Если появилась новая тема, добавить страницу и ссылку в `index.md`.

## Как обрабатывать исторические чаты

Использовать правила из [chat-ingest.md](chat-ingest.md).

Коротко:

1. Прочитать чат полностью.
2. Определить тип A или B.
3. Для типа A сохранить summary в `raw/chats/YYYY-MM-DD-тема.md`.
4. Сверить факты из чата с текущим кодом и актуальными документами.
5. При конфликте не обновлять wiki автоматически, а спросить пользователя.
6. Если конфликтов нет, обновить wiki, `sources.md` и `log.md`.

## Формат записи в log.md

```md
## [YYYY-MM-DD] тип | Краткое название

- Источник: файл, чат, встреча, Swagger, скриншот.
- Что добавлено: кратко.
- Какие страницы обновлены: список ссылок.
```
