## Include-связи

- UC-01 включает UC-03.
- UC-01 включает UC-04, если есть ошибки.
- UC-02 включает UC-03.
- UC-05 может включаться в UC-01, UC-02, UC-03 и UC-12.
- UC-12 использует UC-18 как источник правил сопоставления.
- UC-14 включает проверку всех позиций.
- UC-17 включает UC-19.

## Extend-связи

- UC-06 может быть расширен UC-04, если есть блокирующие ошибки.
- UC-07 может быть расширен UC-08, если согласующий возвращает ДВ.
- UC-09 может быть расширен UC-10, если координатор СМАКС возвращает заявку.
- UC-12 может быть расширен UC-13, если сметчику нужно уточнение.
- UC-15 может быть расширен UC-16, если старший сметчик возвращает смету.
- UC-21 выполняется только после статуса, разрешающего выгрузку.
